The Funny Architecture Simulator

A toy you drag around until you feel why architecture is not slider-math.

This is a lens, not a calculator. The model is a toy — inspect it, distrust it. It never tells you which box to build; it only shows the forces doing the naming.

The forces
The thin bar under each slider = local sensitivity: how much the whole picture would shift if you nudged this force right now. It is not importance — a flat bar means low leverage here, not never. Drag one and watch the others change — that interaction is what complexity is.
Where you're standing — Grady's axes
These don't move your dot in the field — they reshape what your position means: how much a machine can be trusted, and how much the system costs to run.

The field

Where the forces place you. The map moves, not just the dot. Wildcards leave a breadcrumb trail — the story of how you got here.

Grady's corner — can a machine be trusted here?

Green where a machine can be trusted; red in the stacks. High stakes alone dim trust a little — routine work survives them, with review. It collapses where stakes and novelty combine. The trap: the agent sounds just as sure in the red — its fluency stays high exactly where your trust should drop.

boundaryCost        = (async + state + 0.5 + 0.4×deploymentScale) × (1.5 − opMaturity)
                      // scale prices every seam: rollout coordination, config drift
stayingTogetherCost = changeRate × coupling × (0.5 + complexity)
failureSurface      cliff mode (default):
                      if (async>0.6 && state>0.6 && opMaturity<0.4)
                          → high plateau   (this is the snap)
                      else → low, gentle
                    smooth mode:
                      gentle + gate × (plateau − gentle)
                      gate = σ((async−0.6)/0.05) × σ((state−0.6)/0.05)
                           × σ((0.4−opMaturity)/0.05)
                      // same forces, same steepness — but no magic number where
                      // 0.59 and 0.61 are different worlds. The cliff is the
                      // dramatic lie; the sigmoid is closer to how systems degrade.
decisionPressure    = (blastRadius + irreversibility) / 2
                      // low → cheap & reversible → delay; high → decide deliberately

structuralNovelty = 0.45×coordinationNovelty + 0.30×complexity + 0.25×(1−familiarity)
agentTrust        = familiarity × (1 − 0.3×blastRadius − 0.6×blastRadius×structuralNovelty)
                    // stakes alone only dim trust; stakes × novelty collapse it.
                    // routine work in a high-stakes domain stays workable — with review.
observabilityNeed = async × (0.5 + 0.5×state) × (0.5 + 0.3×coupling + 0.2×deploymentScale)
                    // deployment scale buys its own observability bill
observabilityGap  = observabilityNeed − opMaturity     // red when the team can't pay it
debuggingPain     = asyncKnee(async) + 0.4×coupling    // knee at async 0.5; clamps at 1
cognitiveLoad     = (coupling + 0.25×coordinationNovelty) × (0.4 + 0.6×async) × (0.5 + 0.5×state)

safetyPenalty     = 0.18×(1−opMaturity)×async + 0.12×blastRadius×state
                    + 0.20×max(0, observabilityGap) + 0.10×failureSurface
                    // a thin team can't safely run a hard boundary — this pushes
                    // the region lines toward "keep together". The map moves.

field x = stayingTogetherCost      field y = boundaryCost
region  = sign(x − y − safetyPenalty); not-ripe band width ∝ (1 − decisionPressure)
so opMaturity & blastRadius move the region lines, not just the dot.
wildcards drop a breadcrumb where you stood — the trail is the story, not the dot.
pinning freezes a ghost dot; the delta panel compares pinned vs now. Note the
ghost sits on the *live* map — its own world bent the region lines differently.

leverage bar      = local sensitivity, not importance: a finite-difference gradient
                    of the whole output vector for a small nudge of this force,
                    capped to a stable visual scale. Flat means nudging it changes
                    little from *here* — it says nothing about elsewhere.
